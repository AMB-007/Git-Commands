# Git Practice

This repository contains documentation and examples for learning and practicing Git commands.

## Overview

This project is designed to help you understand and practice common Git commands and workflows.

## Git Commands Reference

### Basic Commands

#### `git status`
Shows the current status of your files and repository.

#### `git init`
Creates a new Git repository in the current directory.

#### `git add`
- `git add .` - Adds all changed and untracked files to the staging area
- `git add <filename>` - Adds a specific file to the staging area (e.g., `git add sample.py`)

#### `git commit`
Saves changes permanently in Git with a message.
```bash
git commit -m "Your commit message here"
```

#### `git log`
Displays the complete commit history of your repository.

### Bonus Commands

#### `git diff`
Shows the differences between modified files and the last commit.

#### `git restore`
Restores files to their previous state or removes them from the staging area.

## Getting Started

2. Use the commands above to practice Git workflows
3. Refer to `sample.py` for quick reference on Git commands
